# 📌 Dvach Telegram Bot

Telegram-бот для мониторинга тредов имиджборда 2ch (Двач) и публикации постов прямо из Telegram с прикреплением медиафайлов и интерактивным решением EmojiCaptcha.

---

## ✨ Возможности

* 🧵 **Мониторинг тредов:**
  * Отслеживание только новых сообщений или полная фоновая загрузка всей истории треда с настраиваемыми паузами для защиты от ограничений Telegram Flood Control.
  * Автоматическое переключение между зеркалами (`2ch.su`, `2ch.life`, `2ch.hk`, `2ch.org`) при недоступности основного домена.
  * Сохранение списка отслеживаемых тредов и конфигурации в `state.json`.

* 🖼 **Работа с медиаконтентом:**
  * Два режима отображения: `preview` (быстрые сжатые превью) и `full` (исходные фото и видео высокого качества).
  * Кнопка **«🔍 Показать оригинал»** под превью — заменяет изображение или видео на полноразмерный оригинал прямо на месте через `editMessageMedia` без повторной отправки в конец чата.
  * Полная поддержка медиагрупп (альбомов), фото, видео, GIF-анимаций, видеосообщений (кружочков) и графических документов.

* ✍️ **Публикация и ответы на 2ch:**
  * **Ответ через Reply:** быстрый ответ на любое сообщение бота в чате (номер `>>12345` и выделенные цитаты подставляются автоматически).
  * **Кнопка «✏️ Новый пост»:** закрепляется под последним сообщением треда — достаточно нажать её и отправить следующее сообщение (текст или медиа) в чат.
  * **Интерактивный черновик:** инлайн-экран настроек перед отправкой позволяет указать имя автора, тему, включить **Sage** или сохранение оригинального имени файла.
  * Поддержка флагов в тексте сообщения: `--name <имя>` и `--subject <тема>`.
  * Возможность прикреплять до 4 файлов к одному посту (лимит API Двача).

* 🧩 **Встроенная EmojiCaptcha:**
  * Отрисовка графического полотна и выбор символов инлайн-кнопками `[ 1 ]`..`[ 8 ]` прямо в Telegram.
  * Поддержка многошаговой капчи с отображением угаданных элементов, автоматический пропуск при наличии VIP/отключении капчи, а также кнопки обновления и отмены.

* 🩺 **Health-check сервер:**
  * Встроенный HTTP-сервер на порту `PORT` / `DVACH_HEALTH_PORT` для мониторинга в PaaS и контейнерах (возвращает статус, аптайм и число активных тредов в JSON).

## 📋 Таблица команд

| Команда | Описание |
| :--- | :--- |
| `/watch <ссылка>` | Начать отслеживание треда (только новые сообщения). |
| `/watch <ссылка> all` | Выгрузить всю историю треда в чат, затем отслеживать новые. |
| `/unwatch` | Вывести нумерованный список тредов с интерактивным выбором для удаления. |
| `/unwatch <ссылка / доска id>` | Удалить конкретный тред из мониторинга. |
| `/unwatch all` | Снять с мониторинга все треды и прервать фоновые выгрузки истории. |
| `/list` | Список отслеживаемых тредов и номера последних прочитанных постов. |
| `/mode <preview\|full>` | Переключить режим медиа: сжатые превью или оригинальные файлы. |
| `/post <ссылка> <текст>` | Опубликовать новый пост в тред по ссылке (поддерживает медиа). |
| `/reply <текст>` | Ответить в тред (используется как Reply на сообщение бота). |
| `/cancel` | Сбросить активное ожидание ввода (нового поста, номера треда или поля черновика). |
| `/chatid` | Узнать ID текущего чата или супергруппы для конфигурации бота. |
| `/status` | Показать состояние бота, текущий аптайм, активное зеркало и параметры задержек. |
| `/start` | Краткая справочная информация по возможностям бота. |

## 🛠 Установка и настройка

### 1. Клонирование репозитория и окружение
```bash
git clone [https://github.com/bagger288/DvachTelegramBot.git](https://github.com/bagger288/DvachTelegramBot.git)
cd DvachTelegramBot

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```
*(Для работы требуется Python 3.10+)*

### 2. Конфигурация (.env)
Создайте файл `.env` в корне проекта по образцу `.env.example`:

```ini
# ОБЯЗАТЕЛЬНЫЕ ПАРАМЕТРЫ:
DVACH_BOT_TOKEN=токен_от_BotFather_для_бота
DVACH_USER_ID=твой_telegram_chat_id

# НЕОБЯЗАТЕЛЬНЫЕ ПАРАМЕТРЫ:
DVACH_POLL_INTERVAL=15       # Интервал опроса тредов в секундах
DVACH_HISTORY_DELAY=2.5      # Пауза между отправками постов при загрузке истории (/watch all)
DVACH_LIVE_DELAY=1.5         # Пауза между отправками постов при получении новых сообщений
DVACH_DOMAIN=[https://2ch.su](https://2ch.su)  # Основное рабочее зеркало 2ch
DVACH_HEALTH_PORT=8080       # Порт health-check (0 — отключить)
```
*(Параметры также можно передавать напрямую через переменные окружения ОС)*.

### 3. Получение chat_id
1. Запустите бота и напишите ему в личном диалоге или добавьте в группу/супергруппу.
2. Отправьте команду `/chatid` — бот пришлёт ID чата.
3. Укажите полученное значение в `DVACH_USER_ID`. В супергруппах (начинающихся с `-100`) бот формирует нативные внутренние ссылки вида `t.me/c/...` для цитируемых постов.

### 4. Запуск бота
```bash
python dvach_bot.py
```

## 💡 Основные сценарии работы

### Мониторинг треда
* **Отслеживание новых ответов:**
  ```text
  /watch [https://2ch.su/b/res/123456.html](https://2ch.su/b/res/123456.html)
  ```
  Бот зафиксирует последний пост и будет присылать только новые сообщения.
* **Загрузка всей истории:**
  ```text
  /watch [https://2ch.su/b/res/123456.html](https://2ch.su/b/res/123456.html) all
  ```
  Бот последовательно выгрузит всю историю обсуждения с интервалом защиты от лимитов Telegram, после чего продолжит отслеживать свежие посты.

### Публикация на Двач
1. **Быстрый ответ (Reply):** Ответьте через функцию «Ответить» (Reply) Telegram на любое сообщение треда в чате текстом или медиафайлом (либо напишите `/reply Текст`).
2. **Через кнопку «✏️ Новый пост»:** Нажмите кнопку под последним сообщением треда и отправьте текст или медиа в чат — бот автоматически привяжет пост к нужному обсуждению.
3. **Прямой командой:**
   ```text
   /post [https://2ch.su/b/res/123456.html](https://2ch.su/b/res/123456.html) Текст поста --name Аноним2 --subject Заголовок
   ```
4. **Решение капчи:** Бот отобразит меню настроек поста (имя, тема, Sage, имя файла) и после подтверждения пришлёт картинку EmojiCaptcha. Нажмите кнопки с номерами нужных символов — после решения пост будет опубликован на 2ch.

## 🩺 Health-check сервер

Если задан `PORT` или `DVACH_HEALTH_PORT` (больше `0`), бот поднимает легковесный HTTP-сервер. Любой входящий `GET`-запрос возвращает JSON с метриками:
```json
{
  "status": "ok",
  "bot": "dvach_telegram_bot",
  "threads_count": 1,
  "uptime_seconds": 3600
}
```
*(Для отключения сервера укажите `DVACH_HEALTH_PORT=0`)*.
