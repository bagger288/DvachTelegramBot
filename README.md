# Dvach Telegram Bot

Telegram-бот для мониторинга тредов 2ch (Двача) и публикации постов прямо из Telegram.

Бот умеет:

- получать новые посты из отслеживаемых тредов через API 2ch;
- загружать текущую историю треда или продолжать мониторинг только новых постов;
- отправлять текст, изображения, GIF и видео в Telegram с сохранением форматирования;
- публиковать ответы и новые посты на 2ch, включая вложения и до 4 файлов в одном посте;
- показывать и решать EmojiCaptcha 2ch кнопками в Telegram;
- переключаться между превью и оригинальными файлами;
- сохранять список отслеживаемых тредов и настройки в `state.json`;
- отдавать HTTP health-check для облачного хостинга.

## Требования

- Python 3.10 или новее;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather);
- доступ к API Telegram и одному из зеркал 2ch.

## Установка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd DvachTelegramBot
```

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Создайте бота в BotFather командой `/newbot` и сохраните выданный токен. Не добавляйте токен в исходный код и не публикуйте его.

Для первого запуска задайте обязательные переменные окружения:

```bash
export DVACH_BOT_TOKEN="123456789:укажите_токен_бота"
export DVACH_USER_ID="123456789"
python dvach_bot.py
```

`DVACH_USER_ID` — Telegram ID личного чата, группы или супергруппы, куда бот будет отправлять новые посты. Узнать ID можно командой `/chatid` после запуска. Для супергруппы это обычно число вида `-100...`; его можно передать как есть.

Для постоянного запуска удобно использовать `.env`-файл или менеджер процессов (systemd, Docker, supervisor). Файл `state.json` создаётся автоматически рядом с `dvach_bot.py`, поэтому процесс должен иметь права записи в каталог проекта.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `DVACH_BOT_TOKEN` | нет | Токен Telegram-бота, обязательная переменная |
| `DVACH_USER_ID` | `0` | ID чата для уведомлений, обязательная переменная |
| `DVACH_POLL_INTERVAL` | `15` | Интервал проверки новых постов, секунд |
| `DVACH_HISTORY_DELAY` | `2.5` | Пауза между постами при загрузке истории |
| `DVACH_LIVE_DELAY` | `1.5` | Пауза между новыми постами при мониторинге |
| `DVACH_DOMAIN` | `https://2ch.su` | Основное зеркало 2ch |
| `DVACH_HEALTH_PORT` | `8080` | Порт health-check; `0` отключает сервер |
| `PORT` | не задан | Имеет приоритет над `DVACH_HEALTH_PORT`, удобно для PaaS |

Пример запуска с дополнительными настройками:

```bash
DVACH_BOT_TOKEN="..." \
DVACH_USER_ID="-1001234567890" \
DVACH_POLL_INTERVAL="20" \
DVACH_HEALTH_PORT="8080" \
python dvach_bot.py
```

## Команды бота

| Команда | Описание |
| --- | --- |
| `/start` | Показать справку и основные сценарии работы |
| `/chatid` | Показать ID текущего чата для настройки `DVACH_USER_ID` |
| `/watch <ссылка>` | Начать отслеживать только новые посты треда |
| `/watch <ссылка> all` | Отправить в Telegram всю историю треда, затем продолжить мониторинг |
| `/unwatch` | Показать нумерованный список отслеживаемых тредов для удаления |
| `/unwatch <ссылка>` | Остановить отслеживание конкретного треда |
| `/unwatch all` | Удалить все отслеживаемые треды и остановить загрузку истории |
| `/list` | Показать отслеживаемые треды и номер последнего поста |
| `/mode preview` | Использовать быстрые сжатые превью вложений |
| `/mode full` | Использовать оригинальные файлы высокого качества |
| `/status` | Показать состояние бота, интервал опроса, зеркало и uptime |
| `/post <ссылка> <текст>` | Создать новый пост в указанном треде |
| `/reply <текст>` | Ответить на тред через Reply; номер цитируемого поста подставится автоматически |
| `/cancel` | Отменить активное ожидание нового поста или выбор треда |

Ссылки на тред имеют формат `https://2ch.su/<доска>/res/<номер>.html`. Также вместо ссылки для операций удаления можно передать доску и номер: `/unwatch b 123456`.

## Мониторинг тредов

Добавьте тред командой:

```text
/watch https://2ch.su/b/res/123456.html
```

По умолчанию бот начнёт с последнего уже существующего поста и будет присылать только новые. Чтобы получить всю историю:

```text
/watch https://2ch.su/b/res/123456.html all
```

Под последним сообщением треда бот добавляет кнопку «Новый пост». Нажмите её и отправьте следующее текстовое сообщение, фото или видео, чтобы подготовить публикацию в этом треде.

## Публикация на 2ch

Варианты публикации:

```text
/post https://2ch.su/b/res/123456.html Текст нового поста
```

Или ответьте командой `/reply` на сообщение бота, содержащее пост из отслеживаемого треда:

```text
/reply Текст ответа
```

К `/post`, `/reply` и обычному сообщению можно прикрепить фото, видео, GIF или поддерживаемый документ. Перед отправкой бот покажет настройки поста, где можно включить Sage, указать имя и тему. Имя и тему также можно передать в конце текста:

```text
Текст поста --name Аноним2 --subject Заголовок треда
```

Публикация проходит через EmojiCaptcha 2ch: выберите на изображении нужные эмодзи кнопками в Telegram. Максимум — 4 файла на один пост; лишние файлы не отправляются.

## Health-check

При `PORT` или `DVACH_HEALTH_PORT` больше нуля бот запускает HTTP-сервер на `0.0.0.0:<порт>`. Любой GET-запрос возвращает JSON со статусом, количеством отслеживаемых тредов и временем работы:

```bash
curl http://localhost:8080/
```

Чтобы отключить health-check локально, запустите бот с `DVACH_HEALTH_PORT=0`.

## Примечания

- При недоступности основного домена бот автоматически пробует зеркала `2ch.life`, `2ch.hk` и `2ch.org`.
- Настройки и прогресс мониторинга хранятся в `state.json`; сделайте резервную копию этого файла перед переносом бота.
- В Telegram и на 2ch действуют собственные ограничения частоты запросов. Параметры задержек можно увеличить при большом количестве постов или тредов.
